# ADR-0004: i18n 전략

- 상태: Accepted
- 날짜: 2026-05-12
- 결정 확정: 2026-05-14 (DECISIONS.md Q1-Q16 일괄 권장 동의)
- 결정자: lab-trading 메인테이너 (사용자 결정 필요)
- 관련 ADR: ADR-0002 (스택), ADR-0014 (메뉴)

## 컨텍스트

yutils는 ADR-0003에서 옵션 A(한국어 우선) → B(처음부터 한·영 동시)로 변경했다. lab-trading은 사용자 요구사항에 언어 정책이 명시되지 않았다. 데이터 자체는 글로벌(코인+미장)이고, 종목명은 데이터 원본 언어를 그대로 노출(`Apple Inc.` / `삼성전자`)하지만, UI 라벨·헤더·메뉴·면책 문구는 언어 결정이 필요하다.

## 검토한 옵션

### A. 한국어 단독 출시 → 영어 후속 확장
- 장점: 카피 작성 비용 절반. ko 메시지만 채우면 됨. 한국어 SEO 키워드 집중 ("비트코인 시세", "삼성전자 차트", "백테스트").
- 단점: 영어권 트래픽 즉시 차단. 코인·미장은 영어 검색이 더 큰 시장.

### B. 한·영 동시 출시
- 장점: 글로벌 데이터 사이트로서의 정체성. 영어 검색 트래픽 즉시 수용.
- 단점: 카피 2배. 면책·법률·도움말까지 번역 검증 필요. **데이터 페이지의 90% 콘텐츠가 종목명/가격/차트라 i18n 가치가 작은 영역**.

### C. ko 단독 → 영어는 **메시지 키만 잠그고 비활성화**
- 장점: i18n 인프라(next-intl + prefix-everywhere `/ko/...` `/en/...`)를 처음부터 박지만 `/en`은 messages 누락으로 404 또는 fallback. 추후 메시지만 채우면 즉시 활성화. yutils 패턴과 호환.
- 단점: 사용자에게는 사실상 ko 단독으로 보임 (옵션 A와 동일한 사용자 경험).

### D. ko 단독, i18n 인프라 자체를 1차 출시에서 제외
- 장점: 최소 작업량. 라우팅 `/crypto`, `/us`, `/kr` 직진.
- 단점: 추후 i18n 도입 시 모든 라우트 변경 + canonical/sitemap/hreflang 재작성. yutils 경험상 후행 도입 비용이 큼.

## 결정

**옵션 C 채택 권장.**

근거:
1. next-intl prefix-everywhere 라우팅을 처음부터 박으면 추후 영어 확장 시 라우팅 변경 0. yutils ADR-0006에서 검증.
2. 1차 출시 카피 작성 비용은 ko 단독으로 절반.
3. `messages/en.json`은 스켈레톤만 두고 실제 활성화는 Phase 2 (트래픽 패턴 확인 후).
4. sitemap은 `lib/i18n/routing.ts`의 `locales: ["ko"]`만 출력 (1차). 영어 활성화 시 `locales: ["ko", "en"]`으로 한 줄 변경.

**잠금 항목:**
- 라우팅: `/<locale>/<path>` (prefix-everywhere, yutils ADR-0006 차용)
- 라이브러리: `next-intl` 4 (yutils ADR-0007 차용)
- 1차 출시 활성 locale: `["ko"]`
- root `/` → `/ko` redirect
- 메시지 파일: `messages/ko.json` (작성), `messages/en.json` (스켈레톤만)

## 결과

### 긍정적
- 1차 카피 비용 절감.
- 추후 영어 확장 시 변경 표면 최소화 (메시지 파일 + locales 배열 + 일부 SEO 메타).
- yutils와 라우팅 패턴 동일 → 부품 재사용 매끄러움.

### 부정적
- 영어권 트래픽 즉시 차단 (Phase 2까지). → 완화: hreflang 미설정이라 영어 검색이 ko 페이지로 잡힐 일은 없음. 영어 검색을 우리가 노리지 않으므로 손실 적음.
- `/en/...` 접근 시 404 또는 빈 페이지. → 완화: middleware에서 `/en/*` 요청을 `/ko/*`로 redirect (Phase 2 활성화 시 제거).

### 따라오는 작업
- `i18n/routing.ts`: `locales: ["ko"], defaultLocale: "ko"`
- `i18n/request.ts`: yutils 패턴 차용
- `messages/ko.json`: 1차 출시 카피 작성
- `messages/en.json`: 빈 스켈레톤 (key 구조만)
- middleware: `/en/*` → `/ko/*` redirect (Phase 2에 제거)
- `app/sitemap.ts`: ko만 출력
