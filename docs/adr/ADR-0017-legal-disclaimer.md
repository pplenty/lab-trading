# ADR-0017: 법률 · 컴플라이언스 · 면책

- 상태: Accepted
- 날짜: 2026-05-12
- 결정 확정: 2026-05-14 (DECISIONS.md Q1-Q16 일괄 권장 동의)
- 결정자: lab-trading 메인테이너 (사용자 확인 필요 — 문구 검토)
- 관련 ADR: ADR-0001 (스코프 명시 제외), ADR-0005~0008 (데이터 출처)

## 컨텍스트

한국에서 운영되는 금융 정보 사이트는 두 가지 법적 위험을 안는다:

1. **자본시장법상 "투자자문업"** — 특정 종목·시점을 추천하면 인허가 필요. lab-trading은 추천 콘텐츠를 1차 출시에서 제공하지 않으므로 회피 가능하지만, **백테스트 결과·랭킹·뉴스 노출이 "추천처럼" 인식되지 않도록** 시각·문구로 명확히 분리해야.
2. **데이터 제공자 ToS** — CoinGecko / Upbit / Binance / Twelve Data / KIS / KRX / OpenDART / RSS 매체별 출처 표기 의무.

## 검토한 옵션

### A. 표준 면책 + 모든 페이지 푸터에 박기
- 장점: 단순, 명확.
- 단점: 문구 일률적으로 노출되어 시각 잡음.

### B. 페이지 종류별 면책 (시세 / 백테스트 / 뉴스 별도)
- 장점: 각 위험에 맞춤.
- 단점: 운영 복잡.

### C. 면책 페이지 별도 + 푸터에 링크
- 장점: 시각 잡음 ↓.
- 단점: 사용자가 안 읽음.

## 결정

**옵션 A + B 혼합 채택.**

- **표준 면책**: 모든 페이지 푸터 (한 줄, 작음)
- **백테스트 결과 박스**: 추가 면책 (눈에 잘 띄게)
- **뉴스 카드**: 출처 + "외부 원문 보기" 명시

**잠금 문구 (1차 출시 한국어):**

### 푸터 (모든 페이지)
> 본 사이트는 정보 제공 목적이며 투자 권유가 아닙니다. 거래 결과의 책임은 사용자 본인에게 있습니다. 시세는 데이터 제공자별 지연이 있을 수 있습니다.

### 백테스트 결과 박스
> ⚠️ **백테스트 결과는 과거 데이터 기반의 시뮬레이션입니다.** 거래 수수료·슬리피지·세금이 단순화되어 있고, 미래 수익을 보장하지 않습니다. 실제 거래 결과와 차이가 있을 수 있습니다.

### 뉴스 카드
> 출처: {매체명} (원문 보기 →)

### Settings 페이지 / About
> lab-trading은 한국 사용자에게 코인·주식 정보를 제공하는 비영리 정보 사이트입니다. 본 사이트는 한국 자본시장법상 투자자문업 또는 투자중개업에 해당하지 않으며, 특정 종목의 매수·매도를 권유하지 않습니다. 사용된 데이터는 다음 출처를 통해 제공됩니다: [출처 목록].

### 출처 표기 (자산 페이지)
- 각 자산 페이지·랭킹·차트 하단: `Data: {provider} · 갱신 {N}초 전 · {실시간 / N분 지연 / EOD}`
- 예: `Data: Twelve Data · 갱신 12초 전 · 미국 실시간`

### 데이터 제공자별 의무
| 제공자 | 표기 의무 |
|---|---|
| CoinGecko | "Data provided by CoinGecko" + 링크 (필수) |
| Upbit / Binance | 출처 표기 권장, 재배포 금지 (화면 표시는 OK) |
| Twelve Data | 출처 표기 권장 |
| KIS / KRX / OpenDART | 출처 표기 권장, 재배포 제한 (자체 서비스 송출은 OK) |
| 뉴스 RSS (한경 / 매경 / 파이낸셜뉴스) | 헤드+요약+원문 링크 패턴 + 출처 표기 |

### 컴플라이언스 체크
- 1차 출시 전 한국 자본시장법 적용 여부 1회 점검 (변호사 검토 권장 — 운영자 결정)
- 데이터 제공자 ToS 6개월마다 1회 재확인
- 운영자 분쟁 발생 시 즉시 해당 데이터 노출 중단 + 출처 재확인

### 약관 / 개인정보 처리방침
- localStorage 외 사용자 데이터 수집 0 (1차 출시)
- 쿠키 사용: 인증 없음, 분석 도구(예: Plausible) 도입 시 별도 ADR로 결정
- 약관 / 개인정보 처리방침 페이지(`/legal/terms`, `/legal/privacy`) 1차 출시 직전 작성 (Phase 1.0 마지막 작업)

## 결과

### 긍정적
- 법적 위험 최소화.
- 사용자에게 데이터 출처·지연·면책 모두 투명.
- 백테스트 결과가 "추천"으로 오해될 가능성 차단.

### 부정적
- 문구가 길어 푸터·결과 박스 시각 무거움. → 완화: 작은 폰트 + 회색 + collapse 가능.
- 데이터 제공자 ToS 변경 모니터링 부담. → 완화: 6개월 주기 운영 체크 일정.
